# Localhost Pet Shop Website

Web semester project: **PHP + MySQL** pet-shop pages (`index.php`, customer/admin login, product HTML) with `db_connect.php` and `style.css`.

```bash
git clone https://github.com/hamza2324/Localhost_Website.git
```

Serve with a local Apache/PHP stack (XAMPP/WAMP) and create the MySQL database expected by `db_connect.php`. Do not expose real credentials; review `db_connect.php` before running.

Academic localhost prototype.
